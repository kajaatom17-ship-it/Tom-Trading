Prix en direct de Kraken, mis à jour toutes les 5 secondes. Les actions sont des jetons Kraken (xStocks) cotés en dollars, convertis en euros. Les lignes pointillées montrent l'entrée, le stop et l'objectif d'une position ouverte.

Ce que voit l'analyste technique

Carnet d'ordres

Gauche : acheteurs (bid). Droite : vendeurs (ask).

Positions ouvertes

Stop : prix auquel la position est coupée pour limiter la perte. Objectif : prix auquel le gain est encaissé. Un short gagne quand le prix baisse.

Historique des transactions

Dernière réunion du comité

Entre les réunions, le trader de garde (le moteur) surveille tout toutes les 5 minutes : il protège les gains et peut entrer seul sur un signal exceptionnel, avec un risque réduit. Le comité se réunit toutes les 30 minutes et contrôle ce qu'il a fait. Chaque agent a son rôle : il donne son avis, conteste les autres, puis le Risk Manager tranche.
